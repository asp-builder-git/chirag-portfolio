# Chirag Gandhi — Personal Site

**Product Manager & Builder.** Built with [Astro](https://astro.build), deployed to GitHub Pages, public from day one.

## Why this exists

This site is both a showcase and a finishing school. Every project on it reached a shareable MLP state before it was published here — and the site itself is the first example: built incrementally, in public, one feature at a time.

## Rules

1. A project counts when a stranger can open it (a URL, a repo, a release).
2. A site section ships only when its underlying project is public.
3. Public repo or it doesn't count.

## Dev

```bash
npm install
npm run dev      # local dev at localhost:4321
npm run build    # static build to dist/
npm run preview  # preview the build
```

## Deploy

Pushed to `main` → GitHub Actions builds and deploys to GitHub Pages.
